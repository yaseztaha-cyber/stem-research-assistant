## Honest interpretation

1. **Did dense embeddings improve retrieval?** Marginally and only with CE: Dense+CE Recall +0.006, Precision +0.052, MRR +0.069, NDCG +0.053 over TFIDF+Simple at 23× latency. Dense alone (0.942) did NOT beat TFIDF+Simple (0.947).
2. **Did the cross-encoder improve ranking?** Modestly: MRR +0.04 (TFIDF), +0.027 (dense); recall mixed (TFIDF+CE recall −0.014). 5× latency cost.
3. **Did better retrieval improve human-rated answers?** NO — Answer Relevance v2 flat 0.608–0.610 across configs; human relevance 3.25/5. Retrieval gains stop at the mock template LLM (retrieval PASS → answer FAIL in 5/12 inspected cases).
4. **Did Answer Relevance v2 correlate with human relevance?** Partially: Spearman ρ=0.391 (moderate-weak), groundedness ρ=0.513 (moderate), citation ρ=0.000 (ceiling effect), coverage ρ=0.457. NOT fully validated; v2 meaning frozen, v3 proposed.
5. **Largest error source?** LLM reasoning (mock snippet selection/truncation), then evidence sufficiency on derived/table cases.
6. **Is Qdrant justified?** NO — vector search is milliseconds (DB fetch ~ms of 127 ms total); latency dominated by model inference. SQLite + abstraction retained.

## Fixes implemented (evidence-based, benchmark-validated)

- Mock equation-priority: prefer query-matching known equations over incidental "T = 120K" (fixed power equation wrong answer; general, not case-specific).
- `*`-stripping in equation normalization (fixed Ohm's-law regression V=S→V=IR).
- Experimental-result snippet scoring by query numbers + anti-truncation (fixed 14% and "5." truncation cases).
- Query-type-aware reranker section preferences (resolved Failure #1 to rank 1; Failure #2 in top-5). Full-benchmark recall stable (0.947), no overfitting.

## Limitations & next step

Small corpus (26 embeddings, 0.48 MB DB); TFIDF refit order causes ±0.01 run variance; mock LLM caps answer quality; n=12 human sample. Next: full 100-case human grading, OpenAI-LLM A/B to test whether retrieval gains reach answers, answer_relevance_v3 with tolerance-aware numeric matching.
